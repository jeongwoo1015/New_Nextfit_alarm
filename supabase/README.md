# Re:Spec 최종 DB (정식 개발용)

최종 DB 테이블 정의서 기준 스키마입니다. 프로토타입 DB와는 **다른 Supabase 프로젝트**에 만듭니다. 프로토타입 시연은 기존 프로젝트를 그대로 씁니다.

## 실행 순서
새 프로젝트의 SQL Editor에서 순서대로 전체 실행합니다.

| 순서 | 파일 | 내용 |
| --- | --- | --- |
| (0) | `00_reset_all.sql` | 테이블과 함수를 모두 지움. 구조를 처음부터 다시 만들 때만. 되돌릴 수 없음 |
| 1 | `01_schema.sql` | 테이블 15개, 값 검사, 인덱스, 트리거, 함수 |
| 2 | `02_security.sql` | RLS 정책, Storage 버킷 4개와 권한 |
| 3 | `03_seed_presets.sql` | 초기 프리셋 5종(M~Q), 항목 24개, 고정 스크립트 |
| 4 | `04_check.sql` | 확인 쿼리. 블록을 하나씩 선택해서 실행 |
| 5 | `05_test_data.sql` | 데이터 넣기 테스트. 테스트 계정이 필요하고 마지막 블록에서 지움 |

## 구조 요약
- 앱은 DB에 직접 접근하지 않고 FastAPI 서버를 거칩니다. 서버는 service_role 키를 쓰고, 로그인 토큰의 user_id를 코드에서 확인합니다.
- RLS: 사용자 데이터는 본인 행만, 프리셋·음악은 로그인 사용자 읽기만, 밤 대화 원문(`rs_night_raw`)은 서버만.
- 날짜: `record_date` = KST 현재 − 12시간의 날짜, `apply_date` = `record_date` + 1 (트리거가 계산). 아침 브리핑은 `apply_date` = 오늘인 밤 기록을 씁니다.
- 알람: 루틴 알람(`ROUTINE`) 또는 콘텐츠 알람(`CONTENT`) 중 하나입니다.
- 루틴: 프리셋 항목마다 기본 시간(`default_duration_sec`)이 있고 합계는 10분입니다. 알람 세부 설정에서 항목 시간을 30초 단위로 바꿀 수 있고, 0분이면 그 항목을 뺍니다(`rs_alarm_routine_item`, 바꾼 항목만 저장). 알람의 루틴 합계는 `rs_app_config.routine_max_sec`(900초) 이하입니다.
- 실제 항목 목록과 합계는 함수로 구합니다: `rs_alarm_routine_items(alarm_id)`, `rs_alarm_routine_total(alarm_id)`. 세션 단계를 만들 때는 시간이 0보다 큰 항목만 씁니다.
- 콘텐츠: 고정 시간(`rs_app_config.content_duration_sec`, 팀 확정 후), 단계 내용은 `rs_session_step.step_detail`(JSON)에 둡니다.
- 밤 대화의 하루 한정 변경: 내일 알람 시각(`override_wake_time`), 내일 코칭 안 하기(`override_skip_coaching`).
- 개인화: 전략 로그(`rs_strategy_log`)와 Bandit 상태(`rs_bandit_state`)는 서버만 읽고 씁니다.

## 정의서에 없는데 DB에서 막는 규칙
| 규칙 | 위치 |
| --- | --- |
| 음성 경로는 `{user_id}/{record_date}.m4a`와 정확히 같아야 함 | `rs_night_record` CHECK |
| 사진 경로는 `{user_id}/{diary_date}.jpg`와 정확히 같아야 함 | `rs_diary_photo` CHECK |
| 단계의 user_id = 세션의 user_id, 루틴 단계의 항목은 세션 프리셋의 항목 | `rs_session_step` 트리거 |
| 알람을 지우면 그 알람의 하루 한정 변경값도 비움 | `rs_alarm` 삭제 트리거 |
| 대화 원문(transcript)은 JSON 배열 | `rs_night_raw` CHECK |
| 알람 항목 설정: 루틴 알람에만, 알람 프리셋의 항목만, 30초 단위, 합계 ≤ 상한, 최소 한 항목은 남김 | `rs_alarm_routine_item` 트리거, CHECK |
| 알람 프리셋을 바꾸면 예전 항목 설정 삭제 | `rs_alarm` 수정 트리거 |

## 보관: 스트레칭 일반 버전 스크립트 (10동작, 약 10분 가안)
지금 이 스크립트를 쓰는 프리셋 항목은 없습니다. 콘텐츠 알람의 운동(스트레칭)에 쓸 후보로 보관합니다.

1. 전신 기지개와 손목·발목 깨우기: 누워서 전신을 뻗어 기지개를 켜고, 발목 플렉스·포인트와 바깥·안쪽 회전, 발가락 쥐었다 펴기로 말초 관절을 깨운다.
2. 한 다리 안기 → 양 다리 안기: 두 무릎을 끌어안아 허리 긴장을 푼 뒤, 한쪽 다리씩 가슴 쪽으로 당겨 8초간 유지한다.
3. 무릎 와이퍼와 몸통 트위스트: 머리 뒤에 깍지를 끼고 다리를 넓게 벌려, 팔꿈치를 고정한 채 다리를 좌우로 와이퍼처럼 넘긴다. 이어 무릎을 세우고 손바닥을 붙여 앞으로 나란히 한 뒤, 왼팔을 열며 다리는 오른쪽으로, 오른팔을 열며 다리는 왼쪽으로 천천히 넘긴다.
4. 점진적 다리 뻗기: 한 발씩 천장 방향으로 45도, 55도, 65도, 75도, 90도 순으로 10도씩 높이며 뻗었다 접는다.
5. 브릿지(4박자): 앞으로 나란히 자세에서 발뒤꿈치만 바닥에 대고 ① 팔꿈치로 바닥 누르기 ② 엉덩이 들기 ③ 엉덩이 내리기 ④ 팔 뻗기.
6. 캣 앤 카우: 네발기기 자세에서 숨을 내쉬며 척추를 둥글게 말아 올리고, 들이마시며 가슴을 열어 등과 허리를 유연하게 움직인다.
7. 아기 자세 → 천천히 상체 세우기: 엉덩이를 뒤꿈치에 대고 엎드려 척추와 어깨 긴장을 풀고, 척추를 아래에서부터 차례로 말아 올려 앉는다.
8. 목 스트레칭과 어깨·가슴 열기: 한 손으로 머리 옆을 잡고 고개를 지그시 내려 옆목을 늘리고, 시선을 무릎 방향으로 내려 사선 목 뒤를 늘린다. 두 팔로 W자를 만들어 날개뼈를 모으고, 양손을 어깨에 대고 팔꿈치로 크게 원을 그려 어깨 관절을 푼다.
9. 팔·삼두 → 옆구리: 한쪽 팔을 가슴 앞으로 끌어안고 팔을 머리 뒤로 넘겨 삼두를 늘린다. 깍지를 끼고 정면으로 밀어 등 뒷면을 늘린 뒤, 한 손을 반대쪽 무릎에 두고 다른 팔을 귀 옆으로 길게 뻗어 옆구리를 늘린다.
10. 서서 몸 앞면 늘리기와 깊은 호흡: 양손으로 허리 위쪽을 받치고 배에 살짝 힘을 준 채 가슴과 몸 앞면을 길게 펴고, 깊은 호흡으로 전신을 정리하며 마친다.

동작 구성은 유튜브 3종(심으뜸 10분, 자세 교정 운동, 다노티비 5분)과 비교해 정했습니다.
