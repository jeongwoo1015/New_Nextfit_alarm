# ai/personalization — 개인화

"오늘 이 사용자에게 어떤 방식으로 말할지(전략)"를 정해 Live 지시문 끝에 붙일 문장을 만듭니다. DB를 직접 읽지 않고, 서버가 읽어 넘긴 값만 씁니다.

```
DB 행 → records → user_model(통계) ─┬→ rules ──┐
                                      └→ bandit ─┴→ agent(오늘의 전략 + 로그) → 지시문 끝에 붙임 → Live
하루가 끝난 뒤: reward(결과 점수 0~1) → agent.learn → bandit 학습
```

| 파일 | 역할 |
|---|---|
| `records.py` | DB 행(세션·단계·밤 기록)을 코드가 읽는 형식으로 바꿈 (정의서 컬럼명 기준) |
| `user_model.py` | 지난 7일 통계(기상 성공률, 건너뜀 비율, 루틴 완료율…), 연속 달성일, 일별·주·월·연 집계 |
| `reward.py` | 하루 결과 점수(기상 성공 + 단계 수행 비율) |
| `strategy.py` | 전략 값(코칭 강도·브리핑 길이·응원 정도)과 지시문에 붙일 문장 |
| `rules.py` | 사람이 정한 if-then 규칙 (R0·R1·R3·R4·U1). Bandit과 비교하는 기준 |
| `bandit.py` | 상황 4칸에서 전략 3개 중 하나를 고르고 결과로 배움 (선택 확률 기록) |
| `agent.py` | 위를 묶어 오늘의 전략을 정함. 모드 `off`/`rule`/`bandit`/`ab`, 오류 시 기본 전략 |
| `logs.py` | 전략 선택 로그 한 행 (나중에 효과를 평가하려면 필요) |
| `sim.py` | 가상 사용자로 전체 흐름이 도는지 확인 (`python -m ai.personalization.sim`) |

## 지키는 원칙
- 전략이 없거나 기본이면 대화는 지금과 똑같이 동작합니다(지시문에 아무것도 붙지 않음).
- 어느 단계가 실패해도 기본 전략으로 대화가 이어집니다.
- 피곤한 날과 사용자 말투 설정 `KIND`에서는 강한 전략(`push`)이 나오지 않습니다.
- 위기 여부는 판정하지 않습니다(위기 판정 코드를 만들지 않기로 한 결정).
- 사용자가 고른 어조·말투와 안전 규칙이 전략보다 항상 우선합니다.

## 한계
- 임계값(성공률 50% 등)은 팀장님 자료의 예시를 가정값으로 쓴 것입니다.
- 시뮬레이션은 코드가 도는지 확인하는 용도이며 효과의 증거가 아닙니다.
- 사용자 한 명의 4주 기록으로는 Bandit이 거의 배우지 못합니다(자세한 계산은 `ai/CONTRACTS.md` 6-1).

테스트: `.venv/bin/python -m pytest ai` (Gemini를 부르지 않습니다)
